# Portfolio von Semih Erden

Persönliche Portfolio-Website mit Profil, praktischer Erfahrung, Bildungsweg, Softwareprojekten, IT-Kenntnissen und Kontaktmöglichkeiten. Impressum und Datenschutzerklärung sind als separate Ansichten über den Footer erreichbar.

Die Website verwendet ausschließlich lokale Systemschriften und bindet keine externen Schriftanbieter, Analyse- oder Trackingdienste ein.

## Lokale Entwicklung

```bash
npm install
npm start
```

Die Seite ist anschließend unter [http://localhost:3000](http://localhost:3000) erreichbar.

## Qualitätssicherung

```bash
npm test -- --watchAll=false
npm run build
```

## Deployment

Die Website ist für GitHub Pages konfiguriert:

```bash
npm run deploy
```

Der verlinkte Lebenslauf liegt unter `public/lebenslauf_SemihErden.pdf`.
